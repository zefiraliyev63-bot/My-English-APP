# 📖 My English APP — Учим английский через чтение

**Самый лёгкий способ выучить английский язык, просто читая любимые книги!**

Интерактивное веб-приложение для изучения английских слов в контексте. Вставляйте текст на русском языке, приложение заменяет слова на английские, а вы учите их через озвучку и интерактивное взаимодействие.

---

## 🚀 Быстрый старт

### Онлайн (без установки)
1. Откройте: **[My English APP](https://zefiraliyev63-bot.github.io/My-English-APP/)**
2. Вставьте текст в поле
3. Нажмите **«Преобразовать»**
4. Кликайте по английским словам для озвучки и запоминания

### Локально (на своём компьютере)
```bash
# Клонируйте репозиторий
git clone https://github.com/zefiraliyev63-bot/My-English-APP.git
cd My-English-APP

# Откройте в браузере (двойной клик на index.html)
# или используйте локальный сервер:
python -m http.server 8000
# Затем откройте http://localhost:8000
```

## ✨ Основные возможности

### 1️⃣ **Замена слов на английские**
- Вставьте любой русский текст (книга, статья, новость)
- Приложение случайно заменяет русские слова на английские
- Настройте **плотность замены** (0–80%) через слайдер

### 2️⃣ **Интерактивное обучение**
- **Кликните** по английскому слову → слышите pronunciätion (🔊)
- Слово автоматически отмечается как **выученное** (зелёный цвет)
- Посмотрите русский перевод в **подсказке** (tooltip)

### 3️⃣ **Отслеживание прогресса**
- 📚 **Количество выученных слов** — накапливается по мере обучения
- ⚡ **Количество замен** — сколько слов заменено в тексте
- 📄 **Всего слов в тексте** — общий размер текста

### 4️⃣ **Автосохранение**
- Ваш текст сохраняется автоматически в браузер
- Выученные слова запоминаются (даже если закрыли вкладку)
- Плотность замены сохраняется

### 5️⃣ **Работает оффлайн** 
- Приложение — PWA (Progressive Web App)
- Установите на мобильный телефон через меню браузера
- Работает без интернета после первого открытия

## 🎮 Как пользоваться

### Пример использования:

1. **Вставьте текст**
   ```
   Однажды маленький мальчик вышел в лес. Он видел красивые цветы и слышал поющих птиц.
   ```

2. **Установите плотность** (например, 30%)

3. **Нажмите "Преобразовать"**
   ```
   Однажды small мальчик вышел в forest. Он saw красивые flowers и hear поющих птиц.
   ```

4. **Кликайте по словам**
   - Слышите произношение
   - Слово становится зелёным
   - Счётчик выученных растёт

5. **Сбросьте текст** ("↺ Сброс текста") или удалите прогресс ("🗑️ Сброс прогресса")

## 🐛 Проблемы и решения

### Озвучка не работает
- **Проверьте:** есть ли звук в браузере? Включен ��и микрофон?
- **Решение:** обновите страницу, попробуйте другой браузер

### Слова не сохраняются
- **Проверьте:** включены ли cookies/localStorage в браузере?
- **Решение:** откройте Настройки браузера → Приватность → разрешите LocalStorage

### Приложение медленное
- **Если текст очень большой** (10,000+ слов) — может быть задержка
- **Решение:** разбейте текст на части или используйте меньшую плотность замены
